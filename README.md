# All code for Stanford model + cost-effectiveness analyses for WHO-SAGE TCV single dose & booster modeling exercise 

## data
Files needed to run calibrations, projections, and CEAs

## demographic calibration
Script for running demographic calibration (overall birth rate, age-specific population sizes & mortality rates)

## incidence calibration
Scripts for running incidence calibrations for each of three archetypes (age-specific transmission rates, symptomatic fractions, and overall duration of natural immunity)

## indirect protection + VE and waning calibration
Scripts for running indirect protection calibration under each waning scenario (age-specific VE and waning rates, leakiness parameter, and reduction in infectiousness among the vaccinated)

## projections
Scripts for running projections under each waning scenario, with and without catch-up campaigns 

## CEA
Scripts for conducting cost-effectiveness analyses for all archetype x waning scenario x cost region, with and without catch-up campaigns

## threshold analysis
Scripts for running threshold analysis & combining outputs across archetype x waning scenario x cost region
